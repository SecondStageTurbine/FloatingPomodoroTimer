Yes. For what you’re describing, I would build this as a **native Windows desktop application in C#/.NET using WPF**, not Electron and not a local web server. That gives you a genuinely lightweight floating `.exe`, fast startup, native notifications/audio, low RAM usage, and an interface that can look polished without becoming a huge project.

Pomofocus currently centers around customizable focus/break durations, tasks, estimates, reports, alarm/background sounds, templates, and projects. ([Pomofocus][1]) For your app, I’d deliberately trim that down so it stays focused and lightweight.

# 5. Do NOT implement the timer by subtracting one every second

This is important.

Don't do:

```csharp
remainingSeconds--;
```

That can drift when Windows becomes busy or the computer sleeps.

Instead store the actual target time:

```csharp
DateTime endTime;
```

When Start is clicked:

```csharp
endTime = DateTime.Now.Add(remainingTime);
```

Every UI tick:

```csharp
remainingTime = endTime - DateTime.Now;
```

Now even if the UI temporarily freezes, your timer stays accurate.

# 6. Timer service

The basic idea:

```csharp
public class TimerService
{
    private DispatcherTimer _timer;

    public DateTime EndTime { get; private set; }

    public TimeSpan Remaining { get; private set; }

    public bool IsRunning { get; private set; }

    public event Action<TimeSpan>? Tick;
    public event Action? Completed;

    public TimerService()
    {
        _timer = new DispatcherTimer
        {
            Interval = TimeSpan.FromMilliseconds(250)
        };

        _timer.Tick += Timer_Tick;
    }

    public void Start(TimeSpan remaining)
    {
        Remaining = remaining;
        EndTime = DateTime.Now.Add(remaining);

        IsRunning = true;
        _timer.Start();
    }

    public void Pause()
    {
        Remaining = EndTime - DateTime.Now;

        if (Remaining < TimeSpan.Zero)
            Remaining = TimeSpan.Zero;

        IsRunning = false;
        _timer.Stop();
    }

    private void Timer_Tick(object? sender, EventArgs e)
    {
        Remaining = EndTime - DateTime.Now;

        if (Remaining <= TimeSpan.Zero)
        {
            Remaining = TimeSpan.Zero;

            _timer.Stop();
            IsRunning = false;

            Tick?.Invoke(Remaining);
            Completed?.Invoke();

            return;
        }

        Tick?.Invoke(Remaining);
    }
}
```

# 12. Alarm

Use a bundled `.wav` file.

Something like:

```text
soft-bell.wav
digital-chime.wav
classic-timer.wav
minimal-ding.wav
```

Don't use a harsh Windows beep as the default.

Your audio service can be as simple as:

```csharp
using System.Media;

public class AudioService
{
    private SoundPlayer? _player;

    public void PlayAlarm(string file)
    {
        _player = new SoundPlayer(file);
        _player.Play();
    }

    public void Stop()
    {
        _player?.Stop();
    }
}
```

For volume control, use `MediaPlayer` instead:

```csharp
MediaPlayer player = new MediaPlayer();

player.Open(new Uri(soundPath));

player.Volume = 0.7;

player.Play();
```

# 15. Pomodoro cycle

Logic:

```text
Focus
 ↓
Short Break

Focus
 ↓
Short Break

Focus
 ↓
Short Break

Focus
 ↓
Long Break
```

Then reset the cycle.

Pseudo-code:

```csharp
if (CurrentMode == TimerMode.Focus)
{
    CompletedPomodoros++;

    if (CompletedPomodoros % SessionsBeforeLongBreak == 0)
        SetMode(TimerMode.LongBreak);
    else
        SetMode(TimerMode.ShortBreak);
}
else
{
    SetMode(TimerMode.Focus);
}
```

# 23. Sleep/wake behavior

This needs to be handled properly.

Suppose you start:

```text
25:00
```

then Windows sleeps for 20 minutes.

When Windows wakes, the timer should determine whether the end time has passed.

Because we stored:

```csharp
EndTime
```

instead of decrementing seconds, this is easy.

If:

```csharp
DateTime.Now >= EndTime
```

then mark the session completed.

# 30. Don't forget application signing

Pomofocus itself notes that its Windows download may generate an unsafe-app warning because its application isn't signed with a developer certificate. ([Pomofocus][2])

Your unsigned installer may similarly trigger Windows SmartScreen.

For your own computers that's not particularly important.

If you're going to distribute it publicly, eventually get a code-signing certificate and sign:

```text
FloatingPomodoro.exe
FloatingPomodoroSetup.exe
```
